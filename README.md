# Endless Runner — playable ad (Cocos Creator 3.8.8)

2D-раннер «playable ad»: девочка бежит по улице, перепрыгивает препятствия,
собирает деньги, финиширует через ленту-финиш. На экранах проигрыша/победы —
CTA-карточка (PayPal, «INSTALL AND EARN»). Вся игра упакована в **один
самодостаточный HTML-файл** размером **~3.3 МБ** (лимит — 5 МБ).

## Стек
- **Cocos Creator 3.8.8**, TypeScript, сборка **Web Mobile** (SystemJS + import-map).
- Геймплей целиком процедурный (без сторонних библиотек): спавн по детерминированному
  таймлайну, физика прыжка, параллакс-фон, верле-лента на финише.

## Как игра превращается в один HTML
Cocos собирает игру в папку из множества файлов (движок, JS-чанки, бандлы ассетов,
текстуры, звук). Чтобы получить **один** файл, написан собственный инлайнер
[`tools/inline.js`](tools/inline.js):

1. **Встраивание ассетов.** Все файлы билда кладутся в карту `window.__F__`
   (текст — как есть, бинарные — base64) внутри `<script type="application/json">`.
2. **Перехват загрузок.** `fetch` / `XMLHttpRequest` / `Image.src` переопределены так,
   что движок получает ассеты из этой карты, а не по сети. Для аудио `response`
   отдаёт **свежий** `ArrayBuffer` на каждый доступ (WebAudio «отрывает» буфер при
   `decodeAudioData`).
3. **Загрузка модулей.** `System.instantiate` переопределён: модули исполняются
   `eval`-ом из карты; бандлы `assets/*/index.js` пре-регистрируются, чтобы
   `virtual:///prerequisite-imports/*` резолвились без сети.
4. **Корректная кодировка.** Карта вставляется строго после `<meta charset>`,
   а `<` экранируется в `<`, чтобы `</script>` внутри данных не рвал тег.

## Как уложились в лимит 5 МБ (итог ~3.3 МБ)
- **gzip движка.** Чанк движка `cocos-js/_virtual_cc` (2.4 МБ) грузится только через
  асинхронный импорт SystemJS, поэтому он сжимается gzip-ом на сборке и
  распаковывается в браузере через `DecompressionStream` → **2.4 МБ → 0.6 МБ**.
- **Текстуры** — палитровое сжатие PNG (ffmpeg `palettegen`/`paletteuse`).
- **Аудио** — вырезана встроенная обложка-картинка из mp3 (один эффект весил 299 КБ
  при длине 0.8 с), фон пережат в моно.
- **Spine-рантайм** (~0.6 МБ) исключён из бандла — в игре он не используется.

Весь пост-процесс (выбор свежего билда → сжатие текстур → чистка mp3 → gzip-инлайн →
копия в `docs/`) автоматизирован одним скриптом [`tools/postbuild.ps1`](tools/postbuild.ps1).

## Сборка
```bash
# 1) В Cocos Creator: Project → Build → Web Mobile → Build
# 2) Пост-процесс в один HTML:
powershell -ExecutionPolicy Bypass -File tools/postbuild.ps1
#    -> dist/index.html (и docs/index.html для GitHub Pages)
```

## Требования задания — статус
- ✅ Один самодостаточный HTML ≤ 5 МБ (~3.3 МБ), открывается двойным кликом.

- ✅ Лента-финиш с эффектом «разрыва».
- ✅ Звук (фон + прыжок/монета/проигрыш/победа).
- ✅ CTA-кнопки ведут на внешнюю ссылку.
- ✅ Git с осмысленными коммитами, опубликовано на GitHub Pages.
